# LinkedIn-Job-Insights-Dashboard

SQL-driven analytics platform for exploring LinkedIn job trends, with optimized queries for efficient search, filtering, and visualization.

## Features
- SQL-driven job trend analytics
- Optimized queries for search and filtering
- Data visualization dashboard

## Tech Stack
SQL, Chart.js, JavaScript

## Setup & Run
1. Import the job dataset into your SQL database using `/db/schema.sql`.
2. Configure DB credentials in `/config`.
3. Open `index.html` (or run the local server) to view the dashboard.
