## Overview

An analytics platform for exploring LinkedIn job market trends, built around optimized SQL queries so search, filtering and visualization stay fast even as the underlying job dataset grows.

## Key Features

### SQL driven analytics
Job trend analysis is powered directly by SQL queries against the underlying dataset, rather than precomputed static reports.

### Optimized search and filtering
Queries are structured and indexed for efficient filtering across job titles, locations and other attributes.

### Data visualization dashboard
Results are rendered as interactive charts, making trends easy to read at a glance.

SQL for querying and analytics, Chart.js for visualization, and JavaScript for the interactive dashboard frontend.

## How It Works

Job listing data is stored and indexed in a SQL database. The dashboard frontend sends filter and search parameters to backend queries, which return aggregated results that Chart.js renders as interactive visualizations.

## Setup and Run

1. Import the job dataset into your SQL database using `/db/schema.sql`.
2. Configure database credentials in `/config`.
3. Open `index.html`, or run the included local server, to view the dashboard in your browser.
